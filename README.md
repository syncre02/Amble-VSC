# Amble for VS Code

Release home for the Amble extensions on the Visual Studio Marketplace.

- **Amble** (`amblestudio.lyre-studio`): the Amble Studio workspace, saved host connections and conversations inside VS Code.
- **Amble Agents** (`amblestudio.lyre-agents`): agent controls beside your files and editor. Requires Amble.

Install from the VS Code Extensions view by searching for "Amble", or download a `.vsix` from Releases.
